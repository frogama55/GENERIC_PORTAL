# プライバシーポリシー（NexPortal Mobile）

## ⚠️ 使用は自己責任でお願いします

本スクリプトは非公式の個人開発物です．対象ポータルの仕様変更等により，意図しない表示崩れ・
情報の欠落が起きる可能性があります．

- **読み取り専用です．**成績・出席などの実データ自体を書き換えることはありません．
  ただし**表示が誤っている可能性はあります**．
- **単位・出席・成績・履修登録・締切など重要な情報は，必ず本来のポータル画面でも確認してください．**
  特に履修登録期間・成績発表直後・出席確認や提出物の締切前後は影響が大きくなりやすいため，
  いつも以上に注意してください．
- 表示がおかしいと感じたら：①画面右下の歯車（⚙）から該当機能または全体をOFFにする → ②本来の
  ポータル画面で確認する → ③気づいた点があればリポジトリのIssueで報告する

本スクリプトの利用により生じたいかなる不利益についても，開発者は責任を負いません．

最終更新日：2026年11月

「NexPortal Mobile」（以下「本スクリプト」）は，特定の大学ポータルサイト1つの見た目・表示動作を
見やすく整えるために作られた，非公式の個人開発ユーザースクリプトです（Chrome 拡張機能「NexPortal」のスマホ版）．
本スクリプトは，対象大学・ポータル運営元とは一切関係のない，開発者個人の制作物です．

## 本スクリプトが行うこと

- 対象ポータルのページに CSS/JavaScript を適用し，レイアウト・表示内容を見やすく調整します．
- 設定（各機能の ON/OFF）を，お使いの端末内にのみ保存します．
- 添付ファイルの閲覧など一部の機能で，**対象ポータル自身**へのみ通信を行います（後述）．

## 収集しないもの

本スクリプトは，以下のいずれも収集・保存・送信しません．

- ID・パスワード・トークン等の認証情報
- 個人を特定できる情報
- 閲覧履歴・操作ログ
- Cookie の中身（ブラウザが自動で付与するのみで，本スクリプトのコードが値を読み取ることはありません．
  対象ポータルのセッション Cookie は `HttpOnly` 属性が付いており，そもそも JavaScript から
  読み取れません）

分析・広告・クラッシュレポートなどのテレメトリ機能は一切組み込んでいません．

## 通信について

本スクリプトが通信するのは，**あなたが今アクセスしている対象ポータル自身のみ**です．
開発者のサーバーや，その他いかなる第三者にも，データを送信することはありません．

一部の機能（例：添付ファイルをその場で開く機能）は，あなたが操作したボタンに対応する形で，
対象ポータルへ直接リクエストを送り，その場に表示するために使います．取得した内容は
表示のための一時的なものであり，保存や外部への送信は行いません．

## 保存されるデータ

各機能の ON/OFF 設定のみを，ユーザースクリプト管理アプリ（Userscripts 等）の保存領域
（お使いの端末内のみ）に保存します．この保存領域が使えない環境では，代わりにブラウザの
localStorage（対象ポータルのサイト用の領域．これも端末内のみ）に保存します．
この設定データが本スクリプトの外（開発者・第三者を含む）に送信されることはありません．
スクリプトを削除すると，この設定データも削除されます（localStorage に保存された場合は，
Safari のWebサイトデータを消去すると削除されます）．

## 配布と更新について

本スクリプトは GitHub の公開リポジトリから配布しています．インストール時と更新確認時には，
お使いのユーザースクリプト管理アプリが GitHub（`raw.githubusercontent.com`）へファイルを
取りに行きます．これはアプリによる通常のファイル取得で，ポータル上の情報が送られることはありません．

## 動作範囲

本スクリプトは，対象となる特定の大学ポータルのページでのみ動作します．それ以外のウェブサイトでは
一切のコードが実行されず，何も起こりません．

## 書き込みを行わない設計

本スクリプトは読み取り専用です．対象ポータル上のデータを書き換える操作（フォームの送信・登録等）を，
利用者の明示的な操作なしに行うことはありません．

## ポリシーの変更

本スクリプトの機能追加・変更に伴い，本ポリシーを更新することがあります．重要な変更がある場合は，
このファイルの内容を更新してお知らせします．
