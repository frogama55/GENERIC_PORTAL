# NexPortal Mobile

## ⚠️ 使用は自己責任でお願いします

本スクリプトは非公式の個人開発物です．対象ポータルの仕様変更等により，意図しない表示崩れ・
情報の欠落が起きる可能性があります．

- **読み取り専用です．**成績・出席などの実データ自体を書き換えることはありません．
  ただし**表示が誤っている可能性はあります**．
- **単位・出席・成績・履修登録・締切など重要な情報は，必ず本来のポータル画面でも確認してください．**
  特に履修登録期間・成績発表直後・出席確認や提出物の締切前後は影響が大きくなりやすいため，
  いつも以上に注意してください．
- 表示がおかしいと感じたら：①画面右下の歯車（⚙）から該当機能または全体をOFFにする → ②本来の
  ポータル画面で確認する → ③気づいた点があればリポジトリのIssueで報告する

本スクリプトの利用により生じたいかなる不利益についても，開発者は責任を負いません．

---

某ポータルの見た目及び表示動作を改善する [NexPortal](../cit-portal-ext/)（Chrome 拡張機能）の，
**スマホ版**です．スマホのブラウザには Chrome 拡張を入れられないため，同じ中身を
**ユーザースクリプト**（ブラウザに後付けする小さなプログラム）としてまとめ直しています．

- iPhone / iPad：Safari ＋ 無料アプリ「Userscripts」で動かす想定（費用・期限なし）
- データの外部送信は一切しません（[PRIVACY_POLICY.md](PRIVACY_POLICY.md) 参照）
- ポータルへの書き込みはしません（読み取り専用）
- 対象ポータルの運営元とは無関係の非公式・個人開発物です
- 統合認証（SSO）画面には一切触れません

導入手順は [INSTALL.md](INSTALL.md)，機能一覧は [FEATURES.md](FEATURES.md) を参照してください．

> **現在の状態（v0.1.0）：試作版です．**手元の模擬ページでの動作確認（スタイルの適用・設定パネル・
> 読み込み表示）までは済んでいますが，**スマホ実機でポータルを開いた確認はまだ**です．
> 特に「狭い画面向けのレイアウト調整」と「添付ファイルを開く動作」は実機で見ながら詰める前提です．

## Chrome 拡張版との違い

| 項目 | Chrome 拡張版（cit-portal-ext） | スマホ版（このフォルダ） |
|---|---|---|
| 形 | Chrome 拡張機能 | ユーザースクリプト（1ファイル） |
| 設定画面 | ツールバーのポップアップ | 画面右下の歯車（⚙）ボタン → 設定パネル |
| 添付ファイル | ページ内のビューアで表示 | タッチ端末では「開く／保存」ボタン（画像はその場で表示） |
| レイアウト | PC の画面幅を想定 | 幅 700px 以下向けの調整を追加（`src/mobile/mobile.css`） |
| 更新 | ストアが自動更新 | アプリが更新を検知 → 利用者がタップして更新 |

## 開発者向け：仕組みとビルド

`src/content/` は Chrome 拡張版とほぼ同じコードです．スマホ版だけの部品は `src/mobile/` に分けて
あり，`build.mjs` がそれらを1つのファイルにまとめます．

```
cit-portal-mobile/
  build.mjs                … ビルドスクリプト（外部ライブラリなし）
  package.json             … バージョン番号はここ（"version"）
  dist/
    nexportal-mobile.user.js … 配布する本体（自動生成．直接編集しない）
    nexportal-mobile.meta.js … 更新確認用のヘッダ（自動生成）
  src/
    content/               … 拡張版と共通のコード（restyle.css と各ページ用の .js）
    mobile/
      shim.js              … chrome.storage 等を GM.getValue / GM.setValue の上に再現する互換層
      inject.js            … CSS とページ側ブリッジを差し込む（拡張版の manifest.json の役割）
      page-bridge.js       … ページ側で動く小さなスクリプト（拡張版の loading-bridge.js）
      settings-panel.js    … ページ内の設定パネル（拡張版の設定ポップアップの代わり）
      mobile.css           … スマホ向けの追加スタイル
  test/fixture.html        … ログインなしで基本動作を確かめる模擬ページ
  docs/                    … 要素調査・セキュリティ設計メモ
```

### ビルド

```bash
node build.mjs
```

### 手元での動作確認（模擬ページ）

```bash
python3 -m http.server 8765
```

起動後，ブラウザで `http://localhost:8765/test/fixture.html` を開きます（開発者ツールでスマホ幅に
すると確認しやすい）．模擬ページなので，ポータル固有の画面（時間割・成績・出欠など）は確認できません．

### 更新を配る手順

1. `src/` を修正する
2. `package.json` の `"version"` を上げる（上げないと利用者側で更新として検知されません）
3. `node build.mjs` を実行する
4. `dist/` を含めてコミットし，`main` に push する

利用者のアプリは `@updateURL`（`dist/nexportal-mobile.meta.js`）のバージョンを定期的に見て，
新しければ更新を案内します．

### Chrome 拡張版の変更を取り込むとき

`../cit-portal-ext/src/content/` の変更を `src/content/` に反映します．スマホ版だけの変更箇所には
コード中に **【スマホ版】** というコメントを付けてあるので，そこを消さないように注意してください
（`restyle.js` のスクロールロック，`loading.js` の開始条件，`attachment.js` のビューア）．
`restyle.css` は拡張版と同一のまま保ち，スマホ向けの上書きは `mobile.css` に書きます．
