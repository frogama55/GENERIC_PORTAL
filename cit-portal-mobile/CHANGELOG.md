# 変更履歴（NexPortal Mobile）

Chrome 拡張版の変更履歴は [../cit-portal-ext/CHANGELOG.md](../cit-portal-ext/CHANGELOG.md) を参照．

## v0.1.3

- **添付ファイルが新しいタブで開かなかった問題への対処**（v0.1.2 は iPhone 実機で新しいタブが開かず，
  従来のプレビュー画面のままだった）．ブラウザは指でタップした瞬間にしかタブを開かせないが，
  v0.1.2 は「ポータルが送信を始めた時点」で開こうとしていた．ポータルのダウンロードボタンは
  押してから送信までに間があるらしく，その時点ではもう開けなかったと推測．
  - クイック一覧のファイル名をタップした瞬間に空のタブを先に開いて予約し，送信を横取りした時点で
    そのタブへ表示する方式に変更（20秒待っても送信が来なければタブを閉じる）
  - ユーザースクリプトの世界から開けない場合に備え，ページ側（`page-bridge.js`）で開く経路も追加．
    移動先は，このページ自身が作った一時URL（blob:＋ポータルのオリジン）に限定
- 模擬ページのダウンロードボタンを，実機に近い「押してから少し遅れて送信」に変更

## v0.1.2

- **添付ファイルをタップで直接開く**：タッチ端末では，ファイル名をタップしたらプレビュー画面を挟まず，
  新しいタブ（ブラウザ標準のビューア．PDF も全ページ表示・拡大できる）で開くようにした．
  v0.1.1 のページ内表示は，iPhone では PDF が1ページ目しか出なかったため（iOS Safari の制約）．
  タップした瞬間に空のタブを開き，取得できたらそこへ表示する（取得後に開くとポップアップとして
  止められるため）．タブを開けなかった場合は，従来の画面（1ページ目＋「開く／保存」）を出す
- 設定の表示名を「添付ファイルをタップで開く」に変更
- 模擬ページに添付一覧（取得は偽の応答）を追加

## v0.1.1

iPhone 実機（Safari ＋ Userscripts）で試した結果を受けた修正．

- **自前UIの拡大**：このポータルはスマホでも PC 用の幅（約980px）を縮小して表示するため，
  歯車ボタン・設定パネル・添付ビューアの操作部・読み込み中カードも一緒に縮んで小さかった．
  「ページの幅 ÷ 端末の画面幅」を拡大率（`--cit-ui-scale`）として求め，`zoom` で打ち消すようにした
- **添付ファイルをその場で表示**：タッチ端末でも，ファイル名をタップした画面に PDF を直接表示する
  （iframe）．iOS では1ページ目しか出ない可能性があるため，「開く／保存」ボタンと案内は残した
- **「添付資料を確認」ボタン**：クイック一覧を出せたら隠すようにした（押しても読み込み中が出るだけで
  何も起きないように見えていた．不可視にしている添付一覧ダイアログが再読み込みされるだけだったため）
- 模擬ページに，PC 幅のまま縮小表示される場合の版（`test/fixture-pcwidth.html`）を追加

判明したこと：ポータルにはスマホ用の画面幅指定が無いので，`mobile.css` の「狭い画面（幅 700px 以下）
向けのレイアウト調整」は，スマホでは現状効いていない（PC と同じレイアウトが縮小表示される）．

## v0.1.0（試作版）

Chrome 拡張版 NexPortal v0.2.0 をもとに，スマホ向けのユーザースクリプト版を新規作成．

- **ユーザースクリプト化**：`build.mjs` で `src/` を1ファイル（`dist/nexportal-mobile.user.js`）に
  まとめる方式に変更．`manifest.json`・設定ポップアップ・アイコンは削除
- **互換層（`shim.js`）**：`chrome.storage.local` / `onChanged` を `GM.getValue` / `GM.setValue`
  の上に再現（使えない環境では localStorage にフォールバック）．共通コードは拡張版のまま使える
- **ページ内の設定パネル**：画面右下の歯車（⚙）から開くボトムシートに変更
- **添付ファイル**：タッチ端末では iframe ビューアをやめ，「開く（新しいタブ）／保存」ボタンに変更
  （iOS Safari が iframe 内の PDF を1ページ目しか表示できないため）．画像はその場で表示．
  拡張子から MIME を補い，新しいタブで表示されやすくした
- **スマホ向けスタイル（`mobile.css`）**：入力欄フォーカス時の自動ズーム防止，掲示カードの折り返し，
  タブの横スクロール，クイックランチャーの3列化，時間割・出欠表の横スクロール調整など
- **ローディング表示**：ページ側ブリッジを `<script>` 差し込みに変更．差し込めない環境では
  ポータル本来の表示にフォールバック

未確認事項：スマホ実機でのポータル表示，Userscripts アプリでのインストール・更新，
添付ファイルの「開く／保存」の動作．
