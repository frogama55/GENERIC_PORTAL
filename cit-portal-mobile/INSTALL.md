## iPhone / iPad（Safari ＋ Userscripts アプリ）

必要なもの：iOS / iPadOS 15.1 以降

### 1. Userscripts アプリを入れる

App Store で **「Userscripts」**（無料・オープンソース）をインストールし，一度アプリを開きます．
保存先フォルダの設定を求められた場合は，案内に従って設定してください．

### 2. Safari で Userscripts を有効にする

1. 「設定」アプリ →「アプリ」→「Safari」→「機能拡張」→「Userscripts」を開く
2. 「機能拡張を許可」を **ON** にする
3. Web サイトへのアクセス許可は，**対象ポータル（`portal.chibatech.ac.jp`）だけを「許可」**に
   するのがおすすめです（「すべての Web サイト」を許可する必要はありません）

### 3. NexPortal Mobile をインストールする

1. Safari で次の URL を開く

   ```
   https://raw.githubusercontent.com/frogama55/GENERIC_PORTAL/main/cit-portal-mobile/dist/nexportal-mobile.user.js
   ```

2. アドレスバーの拡張機能ボタン（「ぁあ」またはパズルのアイコン）→「Userscripts」をタップ
3. 「インストール」の表示が出るのでタップし，内容を確認して確定する

### 4. 動作確認

1. Safari で対象ポータルを開く
2. 見た目が変わり，**画面右下に歯車（⚙）ボタン**が出ていれば成功です
3. 歯車をタップすると設定パネルが開き，各機能の ON/OFF を切り替えられます

## 設定できる項目

設定は端末内のみに保存されます（外部送信なし）．一部はページを開き直したあとに反映されます．

- NexPortal を有効にする（全体の ON/OFF．OFFで元のポータル表示に戻る）
- 文字を少し大きくする
- トップページを刷新（クイックランチャー＋スケジュール＋掲示）
- 成績を年度学期表示で開く
- 時間割を今学期優先で表示
- 添付ファイルをその場で開く
- 自動ログアウト画面に再ログインボタン
- 読み込み中のアニメーションを表示

## 更新のしかた

Userscripts アプリが定期的に新しい版を確認します．更新があると，Safari の拡張機能ボタン →
「Userscripts」の画面に更新の案内が出るので，タップして更新してください．

案内が出ない・うまく更新されないときは，**手順3の URL をもう一度開いて入れ直す**と最新版になります．

## 一時的に止めたいとき

- 歯車（⚙）→「NexPortal を有効にする」を OFF（元のポータル表示に戻ります）
- または，Safari の拡張機能ボタン →「Userscripts」で本スクリプトを OFF

## アンインストール

Userscripts の画面（またはアプリ）から「NexPortal Mobile」を削除します．
Userscripts 自体も不要なら，アプリを削除してください．

PC の Chrome / Firefox / Safari でも，Tampermonkey 等に同じ URL を入れれば動きます．
