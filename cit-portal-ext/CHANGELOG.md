# 変更履歴

## v0.2.0（作業中）

今回のバージョンアップで対応する4点：

1. **情報照会系テーブルの視認性向上**：学籍情報照会などの「項目名(th) / 値(td)」形式テーブルで，
   項目名列が行ごとに濃紺／薄灰で交互になり縞が読みづらかった問題を修正。
   原因は，サイト既定の `th` に背景**画像**（グラデーション等）が設定されており，
   従来の `background-color` 上書きだけでは消えていなかったこと（`.btnSearch` で
   過去に踏んだのと同じ落とし穴）。`background-image: none !important` を追加し，
   単色の高コントラスト配色に統一。あわせて行の境界線を足して見分けやすくした。
2. **ローディングUIの刷新**：PrimeFaces標準のAJAXイベント（`pfAjaxStart` / `pfAjaxComplete` /
   `pfAjaxError`）を使い，画面上部に薄いプログレスバー（不確定アニメーション）を新設。
   添付ファイルのプレビュー取得中にもスピナーを表示するようにした（`loading.js` 新規）。
3. **添付ファイルへの導線短縮**：掲示詳細ダイアログを開いたときに「添付資料を確認」の
   展開操作を自動化し，ダイアログ下部にファイル名を一覧表示。ファイル名クリックだけで
   （ダウンロードボタンを経由せず）プレビューへ直接遷移できるようにした（`attachment.js` 拡張）。
4. **時間割・成績表の学期優先表示**：時間割ページ（`table.classTable` が前期・後期で2つ並ぶ構造）に，
   成績ページと同じ「学期ごとにページ切り替え」UIを追加し，既定表示を**現在の学期**（今日の日付から
   前期/後期を判定、該当がなければ最新）にした（`timetable.js` 新規）。成績ページは元々
   最新の年度学期を既定表示にしていたため，UIの見た目（プルダウン＋前後ボタン）を時間割ページと
   共通化（`cit-term-*` クラスに統一）。

### 1回目の実機フィードバックによる修正

- **テーブル**：項目名セルは `<th>` ではなく「濃い背景＋白文字」の `<td>` だったため，
  縞で偶数行だけ薄くなり白文字が読めなくなっていた．クラス名に依存せず，文字色が白系の
  `td` を項目名セルと判定して `.cit-label-cell` を付け（restyle.js），単色・濃色文字に統一．
- **ローディングUI**：PrimeFaces の `pfAjax*` は jQuery の trigger なので隔離世界の content
  script では受信できず，バーが一度も出ていなかった．ページ側の世界で動く
  `loading-bridge.js`（manifest `"world": "MAIN"`）でネイティブイベントに変換して受信するよう修正．
  フルPOST遷移中（`beforeunload`）にも表示．
- **時間割**：学期ブロックは `fieldset`（legend「2026年度 後期」）だった．ブロック＝fieldset，
  ラベル＝legend に修正し，「プルダウンは前期なのに表示は後期」のズレを解消．
  今学期判定を **4/1〜9/15＝前期，それ以外＝後期** に変更．
- **添付一覧**：「添付資料を確認」は別ダイアログを前面に開くため，掲示を開くたびに一覧が
  前面に出ていた．一覧ダイアログは閉じずに不可視にし，ファイル名一覧は**掲示ダイアログ本文の
  末尾**に置くよう変更．

### 2回目の実機フィードバックによる修正

- **添付一覧**：掲示の一番下に出る動作は確認済み．同じ一覧が2つ並ぶ重複を修正
  （設置先ごとに1つ，内容の署名で判定）．
- **ローディングUI**：上部プログレスバーは意図と違った（置き換えたいのは「ポータル本来の
  画面中央のローディング表示」）．中央の小さなカード（スピナー＋読み込み中…）に変更．
  ポータル側の表示を隠す処理はセレクタ判明待ち．
- **テーブル**：項目名セルの実クラス（`td.ui-panelgrid-cell.ui-widget-header.rowHeader`）が
  判明したので固定セレクタを併記．

### 3回目の実機フィードバック（DOM確定）による修正

- **ローディングUI**：ポータル本来の表示は PrimeFaces BlockUI（`.ui-blockui-content` の gif）と判明．
  機能ON中はこれを隠し（遮蔽レイヤは透明にして操作防止だけ残す），中央カードに完全に置き換え．
- **時間割**：枠は `fieldset.ui-fieldset.colGakki`（`.ofAuto` は1つで両学期を含む）と判明．
  `.colGakki` を優先して判定．
- **添付一覧**：一覧ダイアログは `#pkx02201:dialog`（`.ui-dialog`）で不可視化が効いていることを確認．

### 追加要望：モーダル中のスクロールロック

- 掲示ダイアログを見ているとき／読み込み中に，カーソルがダイアログの外にあると後ろのページが
  スクロールできてしまっていた（遮蔽はクリックしか止めない）．遮蔽の表示中はダイアログ本文以外での
  ホイール・タッチ・スクロールキーを止めるようにした（restyle.js）．ダイアログ本文の端に達しても
  後ろへ連鎖しないよう `overscroll-behavior: contain` も追加．

### 実装上の注意（残る推測）

- 添付一覧ダイアログのモーダル遮蔽の id が `pkx02201:dialog_modal` であること（PrimeFaces の
  既定の命名．違えば遮蔽が薄く残る）．
