# EPUSUTAIN PORTAL — できること（実装機能一覧）

CIT（千葉工大）ポータル（`portal.chibatech.ac.jp/uprx/*`）を自分用に使いやすくする Chrome 拡張。
**外部送信なし・認証情報を読まない・読み取り専用・ローカル動作**（設計は
[docs/privacy.md](docs/privacy.md) / [docs/security.md](docs/security.md)）。
各機能はツールバーの設定ポップアップで ON/OFF できます。

導入手順は [INSTALL.md](INSTALL.md)、要素の詳細は [docs/selectors.md](docs/selectors.md) を参照。

---

## 全ページ共通（土台の見た目改善）

- フォント・行間・余白・配色を整える／リンク・見出しの視認性向上
- テーブルの縞模様・罫線、フォーム部品・ボタン・スクロールバーの調整
- 「文字を少し大きくする」オプション

## トップページ

- **クイックランチャー**：よく使う項目をアイコンボタン化（掲示 / 時間割 / 出欠 / 成績 / manaba / 証明書）。
  元メニューを代理クリックするので内部遷移もポップアップもそのまま動く
- **掲示（重要）を5件表示** ＋ 「もっと見る（重要の掲示一覧へ）」で掲示一覧の重要タブへ遷移
- インフォメーションのアイコン群・リンクを非表示にして整理
- **掲示＝左 / スケジュール＝右 の2カラム**（画面が狭ければ自動で縦積み）
- **スケジュールの省スペース化**：授業を「教科名・教員・教室・補足」に圧縮、教員／教室を1行に、
  クラスプロファイルボタンとメモ欄を非表示、シラバス照会→「シラバス」に短縮

## 掲示一覧ページ

- 掲示を**カード表示**（カテゴリのバッジ化、長いタイトルは…省略、フラグ/既読ボタンを同じ行に）
- **既読/未読の見分け**：未読＝緑ドット＋濃色太字、既読＝グレー＋背景を落として後退
- **重要**＝赤い左帯＋淡い背景で強調（分かりにくい電球＝新着表示は廃止）
- **タブの絞り込み**：グループ / 掲示一覧 / 未読 / 重要 / フラグつき だけ表示。
  「全表示」→「掲示一覧」に改名、タブ帯の黒背景を白に
- **並び順ツールバーを削除**
- **検索エリアの簡素化**：黄色い検索ボタンを隠してキーワード欄だけ中央に、授業科目欄を削除。
  Enterキーで検索実行（日本語IMEの変換確定Enterは誤検索しない対策込み）

## 添付ファイルのブラウザ内表示

- 掲示の添付（PDF等）を、ダウンロードせず**ブラウザ内のビューアで閲覧**。保存・新しいタブで開くも可
- 仕組み：ポータルへの same-origin fetch → blob 化 → ページ内オーバーレイの iframe で表示。
  取得に失敗したら通常のダウンロードへ自動フォールバック（外部送信なし・認証情報は読まない）

## 時間割ページ

- 「曜日 × 1〜10限」の**コンパクトな表**に整形（内側スクロール枠の高さ固定を解除して全体表示）
- 左端に **時限＋開始時刻**（1限 9:00 〜 10限 18:00）を全時限表示
  （縞模様で偶数の時限番号が消えていた不具合も修正）
- 各コマを **教科名・教員・講義室・シラバスボタン** に圧縮（単位・複数回/定員有バッジは非表示）

## セッション切れ対策

- 自動ログアウト画面（「この画面を閉じてください」）に **「ログインページへ」ボタン**を表示。
  1クリックで再ログインに進める
- ※ パスワードの保持・自動再ログインはしない（安全側に徹する）

## 検索ボタンの配色

- 他ページの黄色い検索ボタンを、拡張のテーマ色（青）に合わせて見やすく

## 戻るボタン修正（試作・既定OFF・非推奨）

- 「戻る」で常に掲示一覧へ飛ばされる問題への試作。ただしこのポータルは内部ページの再取得で
  HTTP 500 になるため実用にならず、既定 OFF・非推奨（コードは残置）

## 設定ポップアップの項目

| 項目 | 内容 | 既定 |
|---|---|---|
| 見た目の改変を有効にする | 全体の ON/OFF | ON |
| 文字を少し大きくする | 本文フォント拡大 | OFF |
| トップページを刷新 | クイックランチャー＋掲示＋スケジュール | ON |
| 添付ファイルをブラウザ内で表示 | DLせず閲覧 | ON |
| 自動ログアウト画面に再ログインボタン | ログインページへの導線 | ON |
| 戻るボタンを直前ページへ | 試作・非推奨 | OFF |

## 対象・制約

- 動作対象は `portal.chibatech.ac.jp/uprx/*` のみ。他サイトには一切影響しない
- 権限は `storage`（設定保存）のみ。外部ドメインへの通信権限は持たない
- データの外部送信なし／認証情報の読み取り・保存なし／サーバーへの書き込みなし（読み取り専用）
