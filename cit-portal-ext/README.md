# GENERIC PORTAL

千葉工大ポータル（`portal.chibatech.ac.jp/uprx/`）の**見た目だけ**を自分用に改善する、個人用の Chrome 拡張機能です。

- データの外部送信は一切しません（[docs/privacy.md](docs/privacy.md) 参照）
- ポータルへの書き込みはしません（読み取り専用）
- 公開しません（Chromeウェブストアには出しません）
- 認証画面（`sso.chibatech.ac.jp`）には一切触れません

実装済みの機能一覧は [FEATURES.md](FEATURES.md)、導入手順は [INSTALL.md](INSTALL.md) を参照してください。

## できること

- フォント・行間・余白・配色・テーブルの縞模様などを見やすく調整
- 掲示一覧（お知らせ）をカード表示にし、既読/未読・重要を見やすく強調
- 掲示タブの絞り込み、検索欄の簡素化・中央寄せ、掲示ダイアログのスクロール速度の正常化
- 添付ファイル（PDF等）をダウンロードせずブラウザ内で閲覧（保存も可）
- 自動ログアウト画面に「ログインページへ」ボタンを出し、1クリックで再ログインに進める
- ポップアップから各機能を ON/OFF 切替（設定は端末内のみに保存。外部送信なし）

### 添付ファイルのブラウザ内表示について

- 添付一覧の「ダウンロード」を、拡張が横取りして**ポータルから直接取得(same-origin)** し、
  ページ内のビューアで表示する。ダウンロード（保存）や新しいタブで開くのは任意。
- **ポータル以外へはデータを送らない・認証情報は読まない・ファイルは保存しない**（設計は
  [docs/security.md](docs/security.md) 参照）。
- うまく取得できなかった場合は自動で通常のダウンロードに戻る。設定でOFFにもできる。

### 戻るボタン修正について（試作・既定OFF・非推奨）

- 当初「直前ページへ戻る」を実装したが、このポータルの内部ページはサーバー側に
  ビュー状態(JSF ViewState)を持っており、同じURLを GET で取り直すと **HTTP 500** になる。
  この対策は直前URLを取り直す方式のため 500 を踏んでしまい、**このポータルでは実用にならない**。
- そのため既定 OFF（トラップを仕込まないので500も起きない）。コードは `navfix.js` に残置。
- URL再取得が効かない以上、拡張から安全に「直前ページへ戻る」を再現する手段は現状ない。

## インストール手順（デベロッパーモード読み込み）

1. Chrome で `chrome://extensions` を開く。
2. 右上の **「デベロッパー モード」** を ON にする。
3. **「パッケージ化されていない拡張機能を読み込む」** をクリック。
4. このフォルダ（`cit-portal-ext/` = `manifest.json` がある階層）を選択する。
5. 拡張が一覧に表示されれば読み込み完了。

## 使い方

1. ポータル（`https://portal.chibatech.ac.jp/uprx/...`）を開く。
2. 自動で見た目が改善されます。
3. ツールバーの拡張アイコンをクリックすると設定ポップアップが開きます。
   - **見た目の改変を有効にする**：OFF にすると素の見た目に戻ります。
   - **文字を少し大きくする**：本文フォントを少し拡大します。
4. 設定変更は、開いているポータルのタブに自動で反映されます。

## 更新の反映

コードを編集したら、`chrome://extensions` の本拡張カードにある**リロード（↻）**ボタンを押し、
ポータルのタブを再読み込みしてください。

## ファイル構成

```
cit-portal-ext/
  manifest.json          … 拡張の定義（権限は storage のみ）
  src/
    content/
      restyle.css        … 見た目改変の本体（html.cit-restyle 配下に限定）
      restyle.js         … <html> へのクラス付け外し・設定読み込み
    panel/
      settings.html/.js/.css … 設定ポップアップ
  docs/
    selectors.md         … 要素調査の記録（狙い撃ち改善用・随時追記）
    privacy.md           … 外部送信しない設計メモ
  README.md
```
