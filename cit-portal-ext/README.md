# NexPortal

## ⚠️ 使用は自己責任でお願いします

本拡張機能は非公式の個人開発物です．対象ポータルの仕様変更等により，意図しない表示崩れ・
情報の欠落が起きる可能性があります．

- **読み取り専用です．**成績・出席などの実データ自体を書き換えることはありません．
  ただし**表示が誤っている可能性はあります**．
- **単位・出席・成績・履修登録・締切など重要な情報は，必ず本来のポータル画面でも確認してください．**
  特に履修登録期間・成績発表直後・出席確認や提出物の締切前後は影響が大きくなりやすいため，
  いつも以上に注意してください．
- 表示がおかしいと感じたら：①該当機能または拡張機能全体を設定でOFFにする → ②本来の
  ポータル画面で確認する → ③気づいた点があればリポジトリのIssueで報告する

本拡張機能の利用により生じたいかなる不利益についても，開発者は責任を負いません．

---

某ポータルの見た目及び表示動作を改善する，Chromeブラウザ専用の拡張機能です．

- データの外部送信は一切しません（[PRIVACY_POLICY.md](PRIVACY_POLICY.md) 参照）
- ポータルへの書き込みはしません（読み取り専用）
- 対象ポータルの運営元とは無関係の非公式・個人開発物です
- 統合認証（SSO）画面には一切触れません
- 一般公開はしていません（**限定公開**：リンクを知っている人のみインストール可能）

実装済みの機能一覧は [FEATURES.md](FEATURES.md)，導入手順は [INSTALL.md](INSTALL.md) を参照してください．

## できること

- 全体的に，フォント・行間・余白・配色・テーブルの縞模様などを見やすく調整
- 掲示一覧（お知らせ）をカード表示にし，既読/未読・重要を見やすく強調
- 掲示タブの絞り込み，検索欄の簡素化・中央寄せ，掲示ダイアログのスクロール速度の正常化
- 掲示の添付ファイル（PDF等）をダウンロードせずブラウザ内で閲覧（保存も可）
- 自動ログアウト画面に「ログインページへ」ボタンを出し，1クリックで再ログインに進める
- ポップアップから各機能を ON/OFF 切替（設定は端末内のみに保存．外部送信なし）

### 添付ファイルのブラウザ内表示について

- 添付一覧の「ダウンロード」を，拡張が横取りして**ポータルから直接取得(same-origin)** し，
  ページ内のビューアで表示する．ダウンロード（保存）や新しいタブで開くのは任意．
- **ポータル以外へはデータを送らない・認証情報は読まない・ファイルは保存しない**（設計は
  [docs/security.md](docs/security.md) 参照）．
- うまく取得できなかった場合は自動で通常のダウンロードに戻る．設定でOFFにもできる．

## インストール

導入手順は [INSTALL.md](INSTALL.md) にまとめています．

## 使い方

1. 対象ポータルを開く．
2. 自動で見た目が改善されます．
3. ツールバーの拡張アイコンをクリックすると設定ポップアップが開きます．
   - **拡張機能を有効にする**：OFF にすると全機能が止まり，元のポータル表示に戻ります．
   - **文字を少し大きくする**：本文フォントを少し拡大します．
4. 設定変更は，開いているポータルのタブに自動で反映されます．

## 更新の反映

ストア版は自動更新されます．ソースを直接読み込んでいる場合は，`chrome://extensions` の
本拡張カードにある**リロード（↻）**ボタンを押し，ポータルのタブを再読み込みしてください．

## ファイル構成

```
cit-portal-ext/
  manifest.json          … 拡張の定義（権限は storage のみ）
  src/
    content/
      restyle.css        … 見た目改変の本体（html.cit-restyle 配下に限定）
      restyle.js         … <html> へのクラス付け外し・設定読み込み
    panel/
      settings.html/.js/.css … 設定ポップアップ
  docs/
    selectors.md         … 要素調査の記録（開発者向け・随時追記）
    security.md          … セキュリティ設計方針
    privacy.md           … 外部送信しない設計メモ（開発者向け）
  PRIVACY_POLICY.md       … 利用者向けプライバシーポリシー
  README.md
```

## 現在の位置づけ・今後

自分専用として作り始めたものを，限定公開（ストアの Unlisted 機能．検索には出ず，リンクを
知っている人のみインストール可能）の形で共有する方針にしています．対象ポータルの利用規程は
まだ正式に確認できていないため，状況に応じて機能や公開範囲を見直すことがあります．
