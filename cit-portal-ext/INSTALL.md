# EPUSUTAIN PORTAL — 自分のPCへの導入手順

CIT（千葉工大）ポータルを使いやすくする個人用 Chrome 拡張機能です。
Chrome ウェブストアには出していないので、**「デベロッパーモードで読み込む」**方法で入れます。
外部送信なし・読み取り専用・ローカル動作です。

---

## 0. 事前に必要なもの

- **Google Chrome**（この拡張は Chrome 専用。Edge でも同じ手順で動く場合があります）
- **拡張機能一式のフォルダ**（`manifest.json` が入っている `cit-portal-ext` フォルダ）

## 1. フォルダをPCに置く

別のPCへ移す場合は、`cit-portal-ext` フォルダ**ごと**コピーします（中身の構成を崩さないこと）。

```
cit-portal-ext/
  manifest.json        ← このファイルがある階層を後で選ぶ
  src/
    content/  (restyle.css, restyle.js, navfix.js, attachment.js, session.js, topage.js)
    panel/    (settings.html, settings.js, settings.css)
  docs/
  README.md
  INSTALL.md
```

置き場所はどこでもOKですが、**あとで削除・移動しない場所**にしてください（読み込み後にフォルダを消すと拡張も無効になります）。

## 2. Chrome に読み込む

1. Chrome のアドレスバーに `chrome://extensions` と入力して開く
2. 右上の **「デベロッパー モード」** を **ON**
3. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリック
4. 手順1で置いた **`cit-portal-ext` フォルダ**（＝ `manifest.json` がある階層）を選択
5. 一覧に **「EPUSUTAIN PORTAL」** が表示されれば読み込み完了

## 3. アイコンを固定（任意・おすすめ）

- ツールバーの **パズルピース（拡張機能）アイコン** をクリック
- 「EPUSUTAIN PORTAL」の **ピン留めアイコン** を押すと、ツールバーに常駐します
- このアイコンをクリックすると **設定ポップアップ**（各機能の ON/OFF）が開きます

## 4. 動作確認

1. ポータル（`https://portal.chibatech.ac.jp/uprx/...`）を開く
2. 見た目が変わっていれば成功（トップページのクイックランチャー、掲示のカード化 など）
3. ツールバーのアイコンから設定を開き、各機能の ON/OFF を切り替えられます

---

## 使い方（設定ポップアップ）

拡張アイコンをクリックすると、以下を個別に ON/OFF できます（設定は端末内のみに保存・外部送信なし）。

- 見た目の改変を有効にする（全体の ON/OFF）
- 文字を少し大きくする
- トップページを刷新（クイックランチャー＋掲示＋スケジュール）
- 添付ファイルをブラウザ内で表示
- 自動ログアウト画面に再ログインボタン
- 戻るボタンを直前ページへ（※このポータルでは非推奨・既定OFF）

## コードを更新したとき（反映方法）

ファイルを編集したら、変更を反映するには：

1. `chrome://extensions` を開く
2. 「EPUSUTAIN PORTAL」のカードにある **リロード（↻）** ボタンを押す
3. 開いているポータルのタブを **再読み込み**

## 名前・説明文を変えたいとき

`manifest.json` の `name`（拡張名）と `description`（説明文）を編集 → 上記の手順で **リロード**。

## アンインストール

`chrome://extensions` の「EPUSUTAIN PORTAL」で **「削除」**。設定データも一緒に消えます。

---

## うまくいかないとき

- **一覧に出ない / エラーが出る**
  → 選んだフォルダが `manifest.json` の**ある階層**か確認（`src` の中などを選んでいないか）。
- **読み込み時に赤いエラー**
  → カードの「エラー」を開いて内容を確認。`manifest.json` を書き換えた直後なら、括弧やカンマの
    書き間違いがないか確認。
- **見た目が変わらない**
  → ポータルのタブを再読み込み。設定ポップアップで「見た目の改変を有効にする」が ON か確認。
- **フォルダを移動/削除してしまった**
  → 拡張が無効になります。フォルダを元に戻すか、再度「読み込み」からやり直し。
- **アイコンが見つからない**
  → ツールバーのパズルピースアイコンから探してピン留め。

## 注意・前提

- 動作対象は `portal.chibatech.ac.jp/uprx/*` のみ。他サイトには一切影響しません。
- データの外部送信はしません。認証情報（ID/パスワード）を読み取り・保存しません。読み取り専用です。
  （設計の詳細は [docs/privacy.md](docs/privacy.md) と [docs/security.md](docs/security.md) 参照）
- Chrome を更新しても基本はそのまま使えます。デベロッパーモード拡張は、Chrome 起動時に
  「デベロッパー モードの拡張機能を無効にする」という確認が出ることがありますが、
  「拡張機能を保持」を選べば使い続けられます。
