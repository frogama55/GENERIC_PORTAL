# NexPortal — 導入手順

対象は特定の大学ポータル（1サイトのみ）です。それ以外のサイトでは本拡張機能は一切動作しません。

このページは**限定公開**（Unlisted）の拡張機能です。Chrome ウェブストアの検索・一覧には出ません。
**共有されたリンクを知っている人だけ**がインストールできます。リンクは第三者へ転載しないでください。

---

## 方法A：Chrome ウェブストアからインストール（推奨）

1. 共有されたストアのリンクを開く
2. 「Chrome に追加」をクリック
3. 表示される権限（対象ポータルのドメインへの読み取りアクセス等）を確認し、「拡張機能を追加」
4. インストール完了後、ツールバーの拡張機能アイコン（パズルピース）から本拡張をピン留めしておくと
   使いやすくなります

**更新は自動**で行われます。手動での作業は不要です。

## 方法B：ソースコードを直接読み込む（開発者・中身を確認したい人向け）

ストアを使わず、コードを直接読み込むこともできます。機能は方法Aと同じですが、**自動更新はされません**。

1. このリポジトリをダウンロード（「Code」→「Download ZIP」、または `git clone`）
2. Chrome のアドレスバーに `chrome://extensions` と入力して開く
3. 右上の **「デベロッパー モード」** を **ON**
4. **「パッケージ化されていない拡張機能を読み込む」** をクリック
5. ダウンロードしたフォルダの中の **`cit-portal-ext`**（`manifest.json` がある階層）を選択
6. 一覧に **「NexPortal」** が表示されれば読み込み完了

この方法では、更新のたびに最新版を再ダウンロードして手順4〜5をやり直す必要があります。

---

## 動作確認

1. 対象ポータルを開く
2. 見た目が変わっていれば成功（トップページのクイックランチャー、掲示のカード化 など）
3. ツールバーのアイコンから設定ポップアップを開き、各機能の ON/OFF を切り替えられます

## 使い方（設定ポップアップ）

拡張アイコンをクリックすると、以下を個別に ON/OFF できます（設定は端末内のみに保存・外部送信なし）。

- 見た目の改変を有効にする（全体の ON/OFF）
- 文字を少し大きくする
- トップページを刷新（クイックランチャー＋掲示＋スケジュール）
- 成績を年度学期表示で開く
- 添付ファイルをブラウザ内で表示
- 自動ログアウト画面に再ログインボタン
- 戻るボタンを直前ページへ（※このポータルでは非推奨・既定OFF）

## コード（方法Bのソース読み込み）を更新したとき

1. `chrome://extensions` を開く
2. 「NexPortal」のカードにある **リロード（↻）** ボタンを押す
3. 開いているポータルのタブを **再読み込み**

## アンインストール

`chrome://extensions` の「NexPortal」で **「削除」**。設定データも一緒に消えます。

---

## うまくいかないとき

- **ストアで「Chrome に追加」ボタンが出ない**
  → 共有されたリンクが正しいか確認してください（限定公開のため、検索では見つかりません）。
- **学校・会社の管理端末で追加できない**
  → 端末の管理ポリシーで拡張機能のインストールが制限されている場合があります。私物の端末で
    試すか、管理者に確認してください。
- **（方法B）一覧に出ない / エラーが出る**
  → 選んだフォルダが `manifest.json` の**ある階層**（`cit-portal-ext`）か確認してください
    （`src` の中などを選んでいないか）。
- **（方法B）読み込み時に赤いエラー**
  → カードの「エラー」を開いて内容を確認してください。
- **見た目が変わらない**
  → ポータルのタブを再読み込みしてください。設定ポップアップで「見た目の改変を有効にする」が
    ON か確認してください。
- **アイコンが見つからない**
  → ツールバーのパズルピース（拡張機能）アイコンから探してピン留めしてください。

## 注意・前提

- 動作対象は特定の大学ポータル1サイトのみです。他のサイトには一切影響しません。
- 対象ポータルの運営元とは無関係の非公式・個人開発物です。
- データの外部送信はしません。認証情報（ID/パスワード）を読み取り・保存しません。読み取り専用です。
  詳しくは [PRIVACY_POLICY.md](PRIVACY_POLICY.md) を参照してください。
